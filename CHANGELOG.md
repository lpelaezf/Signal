# Changelog

## [1.1] - 2026-08-15

### Added

* Added a more conversational and expressive personality to AI-generated Signals, making summaries feel more natural and engaging.
* Added support for higher-resolution YouTube thumbnails, automatically using the best available image quality.
* Added animated transitions when removing videos from the home screen.
* Added a specific local reset time when the daily API quota has been reached.

### Improved

* Improved reliability when generating Signals that require longer processing times.
* Simplified network error handling.

### Fixed

* Improved item animation behavior while videos are being selected or removed.
